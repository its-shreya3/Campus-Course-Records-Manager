# Project Statement

## Project Title
Campus Course & Records Manager

## Problem Statement
Managing student, course, enrollment, and academic performance records manually can be time-consuming and difficult to maintain. This project provides a simple Java-based system to manage these records efficiently through a command-line interface.

## Objectives
- Manage student records.
- Manage course records.
- Enroll students in courses.
- Record and manage student marks.
- Export academic data into CSV files.
- Create backups of stored data.
- Generate academic reports such as GPA information.

## Functional Requirements
1. Add and list student records.
2. Add and list course records.
3. Enroll students in courses.
4. Record marks for enrolled students.
5. Export data to CSV files.
6. Back up application data.
7. Generate GPA-based reports.

## Non-Functional Requirements
- The system should be easy to use.
- The system should validate user input.
- The system should provide appropriate error handling.
- The system should maintain data consistency.
- The system should provide efficient file processing.

## Technologies Used
- Java
- Maven
- Java I/O and NIO
- CSV file storage
- Object-Oriented Programming

## Expected Outcome
The system provides a convenient way to manage campus course and academic records while reducing manual record-keeping and providing backup, export, and reporting facilities.
